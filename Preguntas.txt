4.¿Para qué sirve Docker Compose? En el mapeo 8000:8000, ¿qué representa el primer 8000 y qué representa el segundo?
para utilizar contenedores docker compose es el que permite configurar y ejecutar varios contenedores juntos, en mi caso compose.yaml define los servicios api y mysql y los levanto con docker compose up
en el primer 8000 es el puerto de mi computadora en donde entro al navegador
el segundo 8000 es el puerto dentro del contenedor que escucha Fastapi

basicamente computadora:contenedor
